# ShopSphere — client

React + Vite frontend for ShopSphere. Setup, environment variables and deployment are covered in the [main README](../README.md).

```bash
npm install
npm run dev     # http://localhost:5173
npm run lint
npm run build
```

Set `VITE_API_URL` (see `.env.example`) to point at an API other than `http://localhost:5000/api`.
